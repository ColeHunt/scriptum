# Methods

Background: [Methods](https://frc-team-4143.github.io/docs/software/java/methods).

All the code lives in `src/Main.java`. Click **Run** any time to see your
methods' output printed to the terminal.

## Contract

- `void stopMotor()` — a `void` method: print `MOTOR STOPPED` to standard
  out and return nothing.
- `double sumThree(double a, double b, double c)` — a method with three
  parameters that returns their sum.
- `String teamName()` — a method with no parameters that returns a fixed
  `String`: your team's name, `"MARS/WARS"`.

## Checking your work

Click **Checkpoints** in the top bar and run **Verify** whenever you want.
